# SnapFit

实验报告图片排版助手。

双击 `打开SnapFit.cmd` 或 `index.html`，在 Edge / Chrome 中打开。无需安装、无需联网。请将 `index.html`、`styles.css`、`layout.js`、`pdf.js`、`app.js` 保留在同一文件夹。

1. 点击添加或拖入 JPG / PNG / WebP 图片，可以分批追加。
2. 在缩略图列表中拖动排序，或使用左右箭头调整顺序；× 删除该图片。
3. 检查每页预览，点击“导出 PDF”。
4. 打印时选择 B5（176 × 250 mm）、实际大小 / 100%，关闭自动适应纸张。打印机的纸盒和驱动也应选择相同纸张尺寸。

## 排版规则

- ISO B5 竖版：176 × 250 mm，四周各 10 mm 页边距。
- 固定三列，横向间距 10 mm，图片宽度 `(176 - 20 - 20) / 3 = 45.333… mm`。
- 图片完整保留原比例、原方向；同一行顶部对齐。
- 每行高度取该行图片的最大高度，下一行从该行下方 10 mm 开始。
- 每页按可用高度连续排列，行数不限。一行放不下时，整行移至下一页；最后一行不足三张时左对齐。
- 单张按统一宽度缩放后高度超过 230 mm 时，界面标出该图，移除或更换后导出。
- 预览与 PDF 共用同一组毫米坐标。PDF 只含图片，界面的页码和说明不参与打印。

图片保存在浏览器本次会话的内存中。刷新或关闭页面后，可重新选择原图片。导出的 PDF 保存到浏览器下载位置。
