# 实验报告图片排版助手

双击 `打开排版助手.cmd` 或 `index.html`，在 Edge / Chrome 中打开。无需安装、无需联网。请将 `index.html`、`styles.css`、`layout.js`、`pdf.js`、`app.js` 保留在同一文件夹。

1. 点击添加或拖入 JPG / PNG / WebP 图片，可以分批追加。
2. 在缩略图列表中拖动排序，或使用左右箭头调整顺序；× 删除该图片。
3. 检查每页预览，点击“导出 PDF”。
4. 打印时选择 B5（176 × 250 mm）、实际大小 / 100%，关闭自动适应纸张。打印机的纸盒和驱动也应选择相同纸张尺寸。

## 确定的排版规则

- ISO B5 竖版：176 × 250 mm，四周各 10 mm 页边距。
- 固定三列，横向间距 10 mm，图片宽度 `(176 - 20 - 20) / 3 = 45.333… mm`。
- 图片完整保留原比例、原方向；同一行顶部对齐。
- 每行高度取该行图片的最大高度，下一行从该行下方 10 mm 开始。
- 每页按可用高度连续排列，行数不限。一行放不下时，整行移至下一页；最后一行不足三张时左对齐。
- 单张按统一宽度缩放后高度超过 230 mm 时，界面标出该图，移除或更换后导出。
- 预览与 PDF 共用同一组毫米坐标。PDF 只含图片，界面的页码和说明不参与打印。

图片保存在浏览器本次会话的内存中。刷新或关闭页面后，可重新选择原图片。导出的 PDF 保存到浏览器下载位置。

PDF 采用最高 600 dpi 的图片分辨率（较小原图保留原始像素尺寸），JPEG 质量 97%，透明区域以白色输出。所有处理在本地完成。

本地验证使用了 14 张示例图片。`example/` 中的原始照片与 `output/` 中生成的 PDF 保留在本地，不纳入 Git 仓库。下载项目后可直接导入自己的图片使用。

## 验证

开发时已在本地完成 17 项排版测试，覆盖空输入、1/3/9/10/14/15/16/18 张图片、超过三行、混合比例、整行换页、页底边界、超高图片与无效尺寸。测试与临时验证资源保留在本地。

已在 Chromium 中验证本地文件打开、批量导入、追加、箭头与拖动排序、删除、清空、PDF 下载、EXIF 方向、透明图及异常图片处理。当前示例的 14 张横图排在一页中，共 5 行。示例 PDF 已渲染检查；文件中的页面尺寸、全部图片宽度与间距也已按毫米核对。实际打印需在对应打印机上按 100% 比例试印。
